> MISSÃO: CRIAR JOGOS COM IA_

Neste projeto, os alunos das turmas 3ºB, 1ºD, 2ºD e 3ºD do curso de Inteligência Artificial aprenderam a usar a IA como parceira para criar seus próprios jogos com vibe coding.

No vibe coding, em vez de escrever cada linha de código sozinho, o aluno descreve sua ideia para a IA, testa o resultado, pede ajustes e repete até o jogo ficar do jeito que imaginou. Todos os jogos foram feitos com HTML, CSS e JavaScript e rodam direto no navegador, no celular, tablet ou computador.
